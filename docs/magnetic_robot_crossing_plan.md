# 磁吸小车跨越钢桥内直角与 U 肋：诊断与改进方案

日期：2026-09-18。状态：**规划，未改代码**。
结论先行：**单纯加大电机扭矩解决不了这个问题。** 当前失败的主因不是扭矩不足，而是**几何尺寸不匹配**与**磁吸模型在棱角处失效**；扭矩甚至不是主要约束。详见 §2、§3。

## 2. 力学判定：扭矩是不是瓶颈

### 2.1 扭矩限幅离滚动需求很远，但离临界需求不够

轮缘可输出的最大切向力：

```
F_wheel,max = T_limit / R = 0.8 / 0.0315 = 25.40 N
```

| 工况 | 切向力需求 | 扭矩需求 | 占限幅 | 判定 |
|---|---:|---:|---:|---|
| 平地 15 rpm 纯滚动（`c_rr=0.01`） | 2.13 N | 0.067 N·m | 8% | 余量 12 倍 |
| **53° 斜壁稳态爬升（两轮贴壁）** | **10.58 N/轮** | **0.333 N·m** | **42%** | **够** |
| 内直角处的车轮翻转（若需翻 4 mm 尖角） | 30.65 N | 0.966 N·m | 121% | 不够 |
| 内直角处的车轮翻转（若需翻 6 mm 尖角） | 128.45 N | 4.046 N·m | 506% | 远不够 |

### 2.2 真正的天花板：轮径，与扭矩无关

刚性轮绕尖锐棱边翻转的准静态解（力矩平衡 `F(R-h) = N√(h(2R-h))`，竖向平衡 `μN = F + W_wheel`）：

任何扭矩下可翻越的等效尖角台阶高度：

| 扭矩限幅 | 最大可翻越 |
|---:|---:|
| 0.4 N·m（减半） | 2.16 mm |
| **0.8 N·m（当前）** | **3.61 mm** |
| 1.6 N·m（2×） | 4.90 mm |
| 3.2 N·m（4×） | 5.78 mm |
| 6.4 N·m（8×） | 6.20 mm |
| ∞（无限扭矩） | **6.20 mm** ← 摩擦上限封顶 |
| ∞ 扭矩 + ∞ 摩擦 | 15.75 mm（`R/2`，几何绝对上限） |

**结论：把扭矩从 0.8 提到 6.4 N·m 只能把可翻越台阶从 3.6 mm 提到 6.2 mm，之后再加扭矩完全无效。** 相对 250 mm 的肋高，这个改善毫无意义。

### 2.3 斜面爬升的摩擦校核（这个反而是够的）

两轮同时贴在 53° 斜壁上：

```
沿坡下滑分量  = W sin53° = 21.15 N
法向合计      = 2×200 + W cos53° = 415.94 N
需要等效 μ    = 21.15 / 415.94 = 0.0509
```

配置 `μ=0.8`，余量 16 倍。**磁吸在斜面上工作良好，牵引不是问题。**

若磁吸完全失效（仅靠重力），需要 `μ ≥ tan53° = 1.33`，远超 0.8 —— 这才是磁吸存在的意义。

## 3. 三个真正的瓶颈

### 3.1 瓶颈一：磁吸模型在 90° 棱角处直接失效（代码级缺陷）

`MagneticAdhesion.cc` 对命中面的法向做双重过滤：

```cpp
if(best.normal.Dot(-down)<.7 || std::abs(best.normal.Dot(axle))>.35) continue;
```

在 90° 内直角处，竖直（或 53° 斜）壁面的法向是横向的，因此 `normal·(-down) ≈ 0 << 0.7`，**该面被直接丢弃**。后果：

- 小车在内直角处接近壁面时，壁面不提供任何吸附采样点；
- 有效样本只剩底面，磁力仍指向底面法向，**完全不产生帮助贴壁或爬升的分量**；
- 若底面样本也因轮子翘起而超距失效，则该轮吸附力归零。

这不是"力不够"，而是"力根本没被生成"。加扭矩无法补偿。

另外，四个采样点的局部 Y 偏移（±0.006 / ±0.014）在 63 mm 窄轮上非常靠内，**棱角处的接触点很可能落在采样点之外**，导致即使法向过滤放宽也可能漏采。

### 3.2 瓶颈二：沿 53° 壁爬升时必然后翻

质心高度估算（车架 + 后电机 + 相机及辅助杆，相机顶部约 `z=0.110 m`）：`h_cg ≈ 0.045 m`。

在 53° 坡上，质心沿坡向后的偏移：

```
h_cg · tan53° = 45 × 1.327 = 59.7 mm
允许最大值      = 轴距/2 = 35.0 mm
余量            = -24.7 mm   →  后翻
```

**这是纯几何结论，与扭矩无关。** 两轮小车 + 高置相机（顶部 110 mm）在 53° 坡上重心投影落在后接地点之外。

### 3.3 瓶颈三：90° 内直角要求车体姿态旋转 90°

从水平底面转到竖直（或 53°）承载面，承载面方向改变约 90°，车体必须相应俯仰。对一个两轮刚性小车：

- 前轮先贴壁、后轮仍在底面时，车体需绕接地点持续俯仰；
- 该过程中质心投影会跑出支撑多边形（同 §3.2，更严重）；
- 转向机构承受非常规载荷：转向轴需抵抗被抬起时的横向力矩，而转向位置环限幅仅 5 N·m。

现有验证覆盖的是"**已贴在某平面上**的驻车与滚动"（`adhesion_wall`/`adhesion_ceiling`/`adhesion_slope` 各 61 s），**没有任何用例覆盖"平面→平面"的姿态过渡**。方案书原文也明确写了这是未验证项：
> "跨越任意 90° 棱边、孔洞或障碍；跨面过渡需要结合真实机构、间隙与后续控制单独验证。"

## 4. 结论：能不能靠加大扭矩解决

| 目标 | 加大扭矩能否解决 | 原因 |
|---|---|---|
| 跨过底板 U 肋（250 mm） | **不能** | 肋高 3.97× 轮径；即使无限扭矩，可翻越上限仅 6.2 mm（摩擦）或 15.75 mm（几何） |
| 越过根部 90° 尖角 | **不能** | 尖角处需要的牵引超过摩擦上限；且磁吸在该处被过滤为零 |
| 爬上 53° 肋壁 | **扭矩够，但会后翻** | 扭矩仅占限幅 42%；失败原因是质心稳定性 |
| 从底面过渡到侧壁（90°） | **不能** | 需姿态旋转 90°，超出两轮刚性小车能力 |

**换句话说，当前"加扭矩"的方向诊断错了。** 扭矩只在"平地滚动"上富余 12 倍，而在真正卡住的地方（棱角、过渡、稳定性）扭矩根本不是约束量。

## 5. 改进方案（按性价比排序）

### P0 — 先做诊断，不要在错误前提上改参数

在改任何东西之前，用**现有**诊断通道跑一次复现，把失败机理定位清楚：

```bash
cd /home/lv/visual_camera_simulate/gazebo_robot
MAGNETIC_ROBOT_DIAGNOSTICS="$PWD/validation/manual/crossing.csv" ./run.sh bridge_robot
# 用车内键盘驱动向底面 U 肋行驶，记录整车穿越过程
```

从 `steps.csv` 要读出四个判据：

1. **前/后轮磁吸力在棱角处是否掉到 0** —— 若是，确诊 §3.1，扭矩无关；
2. **实际关节角速度 vs 目标 15 rpm** —— 若轮子空转（速度远高于目标）而车不动，确诊打滑；若轮子停转而力矩已饱和，确诊扭矩/几何瓶颈；
3. **车体 roll/pitch 是否超过后翻临界** —— 确诊 §3.2；
4. **转向关节实际角度是否被顶开** —— 判断 5 N·m 是否够。

**产出**：一份 `crossing_report.json`，明确写清实际卡点。这是后续所有改动的依据。

### P1 — 修正棱角处的磁吸法向模型（对应 §3.1）

不改几何、只改查询逻辑：

- 放宽/替换 `normal·(-down) > 0.7` 这一"只能吸附当前承载面"的假设，改为**按候选面与轮子的几何关系**接受陡面（例如允许两个正交面同时贡献，各自指向轮子）；
- 轮缘采样点从当前的 4 点增加到覆盖棱角的位置，或改为**沿轮缘圆周采样 + 局部法向聚类**；
- 保留"法向必须指向轮子"的符号约定与"合力不超过 200 N/轮"的归一化约束，避免重复累加。

**验收**：在 `adhesion_wall` 的 90° 内直角处，前轮在贴壁姿态下仍读到 `200 N` 级吸附力，且力的方向同时包含贴壁分量。

### P2 — 给"平面→平面"过渡做专门能力（对应 §3.2、§3.3）

这是任务真正需要的功能，且当前完全缺失。可选路线，从易到难：

1. **路径层面规避（推荐先做）**：通道宽 0.48 m，远大于车宽（约 0.1 m）。巡检方案本来就是"通道内纵向巡检 + 端部换道"，**换道可以走正向板区域，不必跨肋**。先把"沿着通道纵向行驶 8 m"做稳，把跨肋/跨直角降级为可选能力。
2. **降低质心**：把相机及辅助杆的高度纳入稳定性设计，或调整安装位置使 `h_cg·tanθ < 轴距/2`。这是纯几何收益。
3. **增加贴壁辅助自由度**：真正的爬壁机器人普遍用 4 轮 + 万向节 / 柔性车架 / 轮臂，而不是 2 轮刚性车。这属于机构改动，需和实物对照。
4. **增大轮径**：按 §2.2 的模型，翻越 70 mm 尖角需要 `R ≥ 300–400 mm`（轮径 600–800 mm），远大于整车轴距 70 mm。**在现有机构尺寸下不可行**，仅作为原理性说明。

### P3 — 控制策略配套

1. **扭矩限幅**：从 0.8 提到 `1.2–1.6 N·m` 即可覆盖 53° 坡的临界过渡余量（当前 42% 占用）；**不建议**无脑加很大，因为摩擦上限会先成为约束，加大只会增加打滑与翻车风险。
2. **车速环 → 力/力矩控制切换**：当前 `RobotDriveController` 是纯速度环 + 条件积分抗饱和。当轮子被卡住时，速度误差会让积分项饱和并触发抗饱和回退，**恰好削弱了最需要的保持力矩**。建议在检测到"堵转 + 目标速度非零"时切到力控模式，直接给保持扭矩。
3. **转向扭矩**：`5 N·m` 是在平地贴面条件下调出来的。过渡姿态下转向轴的横向载荷尚未测量，应作为 P2 验证的一部分重新确认。

| 阶段 | 工作 | 通过标准 | 风险 |
|---|---|---|---|
| A | P0 诊断复现，产出 `crossing_report.json` | 四个判据均有明确读数，卡点机理唯一 | 低（只记录，不改模型） |

## 7. 本方案的适用边界与未决问题

本方案的数值结论基于：

- 准静态刚体力学（与现有 1 ms 步长、15 rpm 的准静态工况相符），**未含冲击、振动、接触求解抖动**；
- 质心高度 `h_cg ≈ 0.045 m` 为估算值，来自 `generate_assembly.py` 的质量合成（车架 0.408 kg + 后电机 0.31 kg + 杆 0.006 kg + 相机 0.072 kg）。**后翻判定对这一数值敏感**，应以 `runtime/robot_*/assembly.json` 里的 `base_com` 实际值复核；
- 摩擦系数 `μ=0.8` 为配置值，非实测；
- 肋高取 250 mm、根部取 90° 无倒角，取自 STL 量测；**真实钢板焊趾通常有圆角**，若实物有 5–10 mm 焊趾圆角，根部局部接触会明显改善（但仍不足以跨越 250 mm 肋高）；
- 只分析了底板中央通道（CAD `Z=0` 截面）。三道正面板、左右内壁、顶板下侧的几何各不相同，**需分别量测**；
- 未考虑相机与辅助杆在贴近肋壁时的碰撞（相机顶部约 110 mm，横向两侧余量各约 24.5 mm）。

未决问题：

1. `bottom_plane` 的 U 肋与 `top_plane` 的 U 肋朝向相反，两者是否在通道内构成"肋对肋"的窄缝？需要单独量测顶板下侧的净空。
2. 转向关节在过渡姿态下的实际载荷未测。
3. 现有 4 个磁吸采样点是否覆盖棱角接触区，需要用 P0 的 CSV 逐帧核对。

## 8. 复现方式

本方案的全部几何数字来自一次性分析脚本，**不属于工程交付**，位于工作区 `analysis_tmp/`（已在 `.gitignore` 中排除）：

| 脚本 | 产出 |
|---|---|
| `analysis_tmp/transverse.py` | 顶板横截面渲染，确认肋节距与槽形 |
| `analysis_tmp/section_framed.py` | 底板+顶板同图剖面，定位小车行驶面 |
| `analysis_tmp/dihedral.py` | 二面角分布，确认 90° 内直角占主导 |

若要固化这些量测结论，建议后续把截面提取做成工程内的只读工具（例如 `gazebo_robot/scripts/measure_gap.py`），并在 `validation/` 下留存报告，而不是依赖临时脚本。
