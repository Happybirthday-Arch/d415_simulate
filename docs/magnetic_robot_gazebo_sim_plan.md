# 磁吸小车 Gazebo Sim 建模执行方案

日期：2026-09-16。状态：已按本方案完成首版实施；使用说明和实测结果见 [gazebo_robot/README.md](../gazebo_robot/README.md)，验证汇总见 [summary.json](../gazebo_robot/validation/summary.json)。以下保留原执行方案，实际交付差异见文末。

本阶段交付可在现有钢桥中加载的动态小车模型、前轮转向硬限位、每轮 200 N 的理想磁吸物理插件，以及独立验收场景。遥控、运动控制器、路径规划和相机安装放到后续阶段。

**1．已核实的输入与运行环境**

依据 `basic_model/robot_simplified/README.md`、`export_manifest.json`、`simplification_report.json`、`wheel_dimensions.json` 和 `mesh_validation.json`：

| 项目 | 已知情况 |
|---|---|
| 结构 | 前后各一个磁吸轮，共两个轮子；前轮所在组件可以转向 |
| 分部文件 | 车架、转向机构、前轮、后轮、前电机、后电机，共六组 STL |
| 轮子 | 外径 63 mm，总宽 32.5 mm；中央槽底直径 60 mm、槽宽 5 mm |
| 中央槽位置 | 原轮子局部 Z=13.5～18.5 mm，不能擅自改为轴向居中 |
| 装配坐标 | 所有 STL 共用原装配坐标，顶点单位为 mm |
| 前后轮轴 | 原装配 Z 方向；前轮轴约通过 X=-4、Y=7 mm，后轮轴约通过 X=66、Y=7 mm |
| 轴距 | 约 70 mm |
| 轮子轴向位置 | 前后轮略有差别，保留文件中的实际位置 |
| 网格问题 | 两只电机各有 12 条非流形边；其余四组的现有报告未发现此类问题 |
| 质量输入（用户指定） | 单轮 0.70 kg，单电机 0.31 kg，整车假定 2.70 kg；其余结构合计 0.68 kg |
| 待估计物理属性 | 其余结构的质量分配、各部件质心与惯量 |

本机已安装 `libignition-gazebo6 6.18.0`、`ignition-physics5 5.4.0` 和 `sdformat12 12.9.0`；现有 `d415_sim_ws` 已使用 Gazebo Sim Fortress。实施沿用该环境和 DART 物理后端，先核验实际加载的后端。

Fortress 的本地启动方式为 `ign gazebo`，模型资源路径使用 `IGN_GAZEBO_RESOURCE_PATH`，自定义系统插件路径使用 `IGN_GAZEBO_SYSTEM_PLUGIN_PATH`。名称仍带 `ignition` 是该版本的接口约定；本次所有新模型、世界和插件均面向 Gazebo Sim。

复用既有钢桥分部网格、材质和装配位置，以及 `bridge_camera.sdf` 中桥梁绕 X 轴 +90° 的放置方式。旧桥梁 README 中的 Classic 启动命令不作为新工程入口。

**2．沿用钢桥流程，增加动态模型所需步骤**

执行顺序为：源文件核查 → 单位与坐标转换 → 分部网格装配 → visual/collision 分离 → link/joint 与惯性建模 → Sim 世界与插件 → 分级验证 → README 和验证报告。

新建独立目录 `gazebo_robot/`，直接引用已有桥梁模型。源 CAD 和原始 STL 保持可追溯；任何派生网格、碰撞体及转换脚本均写入新目录，并记录输入文件哈希、变换矩阵和近似说明。

**3．坐标与关节拓扑**

车体坐标约定：X 朝前轮方向，Y 向左，Z 离开承载面朝车架。由当前装配姿态初步对应原 CAD 的 `-X、+Z、+Y`，是保持右手性的刚体旋转。以两轮中心附近建立车体参考原点，实施时保存精确变换。

显示网格可保留毫米数值并使用 `scale=0.001`；关节位置、碰撞几何和惯性计算统一使用 SI 单位。原始网格已经带有装配变换，不能再次套用原零件变换。移入 link 局部坐标时使用逆变换，保证零位拼装与整车参考 STL 一致。

建议使用四个动态刚体，六组显示网格分别挂载：

```text
base_link                       车架 + 后电机外壳
├── rear_wheel_joint            连续滚动
│   └── rear_wheel_link
└── front_steering_joint         转向，限定 ±15°
    └── front_steering_link     转向机构 + 前电机外壳
        └── front_wheel_joint   连续滚动
            └── front_wheel_link
```

电机外壳随安装支架运动，不随轮子自转；未单独导出的转子与轴不额外创建虚构刚体。后续若取得转子惯量，可折算到轮轴。

依据轴承和支架的装配数据，转向轴初步判断沿原 CAD Y 方向，约经过 X=5 mm、Z=5.886 mm；前轮轮心 X≈-4 mm，存在约 9 mm 偏置。实施时通过轴承网格的圆柱面/圆环拟合复核转轴，不能直接以轮心或转向组包围盒中心代替。还要核实轴承固定部分与转动部分的分组，必要时对派生网格重新分组。

**4．±15° 转向限位：模型层约束与数值验收**

`front_steering_joint` 使用 `revolute`，标称上下限为：

```xml
<limit>
  <lower>-0.2617993877991494</lower>
  <upper>0.2617993877991494</upper>
</limit>
```

SDFormat 的转动关节限位单位为弧度，参见 [SDFormat joint 规范](https://sdformat.org/spec/1.7/joint/)。轮轴关节单独采用连续旋转，±15° 只限制转向自由度。

用户要求的外部边界始终是 ±15°，不因控制模式变化而放宽。落实方式：

1. 将限位写入物理关节，独立于后续控制器；按合理惯量、步长、阻尼调好接触与关节求解。
2. 在完整转向范围进行几何扫描，计算前后轮、前电机与车架等关键部件的最小间隙，端点附近加密。先核验 ±15° 内确实不会干涉，不通过关闭轮间碰撞掩盖问题。
3. 对上、下限分别施加持续外向测试力矩并记录每个物理步的实际角度，增加较高初始角速度、重置和不同步长工况。
4. 有限步长求解器可能有微小越限；若实测出现这种情况，把内部停止位置向内收紧一个经过测试确定的数值裕量，使外部 ±15° 仍为不可越过的验收边界。报告内部实际可用范围和最大角度。
5. 加入独立限位监测，发现异常越限立即判定失败并停止测试。必要的恢复只用于异常处理，不能用事后裁剪角度或修改日志冒充从未越限。

普通 SDF 限位不能作为任意力矩、任意步长下“数学上绝不超调”的证明。交付必须明确通过验收的步长、力矩和速度范围；以后增加驱动控制时，将命令限制在该已验证范围内。本阶段不以“控制目标只发 ±15°”代替机械限位。

**5．碰撞模型与质量惯量**

显示层使用六组原始外形，保留轮槽、主要孔洞和装配细节；整车 STL 只用于零位装配比对。

轮子碰撞层优先采用同轴三段圆柱：两侧轮缘半径 31.5 mm，中央槽底半径 30 mm，对应轴向长度为 13.5、5、14 mm。根据每只轮子的实际装配方向放置，尤其注意前后轮局部轴向相反。轴孔和键槽保留在显示及惯性计算中，碰撞层允许省略，并记录该近似。

车架、转向机构与电机使用贴合主要外形的多基本体或分块凸碰撞体；避免一个大包围盒封住空隙或扩大转向扫掠范围。两只电机的非流形网格不直接作为动态碰撞网格或未经检查的惯量积分输入。允许对派生副本处理，但不无条件修补、融合原始 CAD。

保留前后轮之间及其他需要检测的非相邻部件自碰撞。装配内固有接触、轴孔近似引起的连接件重叠，仅对明确的连接对做过滤，并验证 Fortress 后端实际生效。

按用户补充，固定以下质量预算：

| 部件 | 数量 | 单件质量 | 合计 |
|---|---:|---:|---:|
| 磁吸轮 | 2 | 0.70 kg | 1.40 kg |
| 电机 | 2 | 0.31 kg | 0.62 kg |
| 车架、转向机构及其余附件的等效质量 | — | — | 0.68 kg |
| 整车 | 1 | 2.70 kg | 2.70 kg |

0.68 kg 的剩余质量暂按 `export_manifest.json` 中车架与转向机构的 CAD 体积比例分配：车架约 0.486219 kg，转向机构约 0.193781 kg。这是本方案的等效分配假设，不是用户提供的分部实测值；后续取得分部质量或整车质心后可调整分配，但总质量保持 2.70 kg。

对应四个动态 link：`base_link`（车架 + 后电机）约 0.796219 kg，`front_steering_link`（转向机构 + 前电机）约 0.503781 kg，`front_wheel_link` 和 `rear_wheel_link` 各 0.700000 kg。生成时使用未舍入数值，并检查四者之和为 2.70 kg。

每个动态 link 都设置正质量、与 link 坐标一致的质心和正定惯量张量。各部件采用上述指定质量，结合经过验证的几何估计质心与单位质量惯量，再用平行轴定理合并刚性部件。电机外壳所在 link 暂计入整台电机的 0.31 kg；以后增加转子惯量时从该预算中重新分配，避免重复计入。轮子的惯量计算保留中央槽、轴孔等几何影响。

整车 2.70 kg 是当前模型的总质量预算，未单独建模的附件质量已等效包含在剩余 0.68 kg 中。后续接入相机等部件时明确其是否属于该预算，并重新分配或更新总质量，不能直接重复叠加。

质量、惯量、摩擦、阻尼和数值步长集中配置。总质量和轮子、电机质量采用用户指定值；剩余质量分布、质心和惯量仍属于几何近似，不能据此宣称整车动力学已完成实物标定。

**6．磁吸实现：每轮总吸力 200 N**

新增 C++ Gazebo Sim System 插件 `MagneticAdhesion`。这是模型物理的一部分，先于控制方式实现。按官方 [System 插件生命周期](https://gazebosim.org/api/gazebo/6/createsystemplugins.html)组织配置、物理步前施力与步后诊断；使用本机版本提供的 [Link 施力接口](https://gazebosim.org/api/gazebo/6/classignition_1_1gazebo_1_1Link.html)。

定义 `n_i` 为钢板局部表面指向轮子的单位法向。单轮有效吸附时：

```text
F_i = -200 * n_i  [N]
```

两轮吸附同一平面时总吸力为 400 N；两轮朝向不同平面时分别计算方向，不能把两个向量强行合成为固定朝下的 400 N。

具体设计：

- 用桥梁模型与 collision 名单显式标记磁性对象。只吸附钢桥对应几何；地面、小车自身与其他物体不因外观颜色自动成为磁性对象。
- 接触传感器用于识别接触对象与核对法向；从桥梁实际三角网格构建空间索引，对轮缘附近做距离、投影和可见性查询，以覆盖微小非接触间隙。不能仅依赖“已经接触才有吸力”，也不能将整块有限钢板替换为无限平面。
- 初始工程参数建议捕获距离 0.5 mm、释放距离 1.0 mm，均指轮缘到钢面的间隙，不是轮心距离。这些是抗抖动的仿真参数，不代表实测磁力曲线。有效状态内每轮保持 200 N；无有效表面或超过释放距离则归零。
- 基于轮缘方向和真实表面确定候选承载面，检查遮挡、孔洞及板边界。对同一平面的多个三角形合并处理，不能按三角形数、接触点数或轮缘数重复施加 200 N。
- 磁力作用在轮子 link 上；需要横向力矩时，以两侧轮缘的有效吸附位置分配总计 200 N 的载荷。多个作用点的权重和为 1，记录合力与合力矩，避免人为锁死车体姿态。
- 法向、施力点和坐标变换使用同一世界位姿。前轮自转后，查询方向仍由承载面与轮轴决定，不能跟随轮子的自转角绕圈。
- 无表面或驶离边缘时正常脱离，保留重力和动力学。磁吸不通过固定到 world、持续设置车体 pose 或关闭重力实现。
- 记录各轮的有效表面、间隙、吸附状态、法向、合力和作用点；插件未加载或磁性对象找不到时显式报错。

采用几何距离辅助接触的方案，主要是保证小间隙时连续吸附，并让倒挂面和双面钢板法向有明确处理；空间查询结果必须与实际碰撞结果交叉验证。

**7．“所有平面上运动”的物理含义与阶段边界**

本阶段把钢桥所有可接触钢面纳入磁性对象，支持水平面、侧壁、斜面和倒挂面；逐类验证局部附着和滚动能力。

磁吸提供法向载荷，沿面驱动和抗滑由轮地接触、轮轴力矩与摩擦共同决定。竖直面上自由轮即便不脱离，也可能向下滚动；没有控制器时，不能将这种滚动误判为磁吸失败。静止驻车测试可临时锁住轮轴，测试夹具不写进正式小车模型。

同面双轮的简化必要条件包括倒挂时 `m*g < 400 N`，竖直面上可用切向附着力满足 `mu*N >= m*g`；实际还要校核质心偏置、轮间载荷和倾覆力矩。摩擦系数先显式配置并做敏感性试验，不通过无限大摩擦或无限大磁力掩盖参数问题。

采用指定质量 2.70 kg、重力加速度 9.81 m/s²，整车重力为 26.487 N。两轮同面总磁吸力 400 N 约为重力的 15.10 倍，仅表示理想静态法向载荷的量级关系；不能代替抗倾覆、接触分配和动态运动验证。

本阶段用临时轮轴力矩验证贴面低速滚动，保留两轮独立转动和前轮转向接口。能够在各平面贴附并滚动，不自动意味着能跨越任意 90° 棱边、孔洞或障碍；跨面过渡需要结合真实机构、间隙与后续控制单独验证。

**8．钢桥碰撞适配**

现有桥梁包含 15 组碰撞网格，相机工程只验证了视觉加载。必须先在 Fortress 中用简单探针检查上下面、侧面、孔洞、U 肋及接缝，确认实际接触位置、法向和薄板两侧都正确。

优先复用现有非凸静态碰撞。如果后端出现封孔、错误凸包或不稳定接触，仅在新工程生成专用碰撞派生模型：钢板按有限板块分解，孔洞保持贯通，U 肋和加强件保留对应轮廓。不得用整个桥箱的大凸包代替。磁性查询与碰撞派生几何使用同一来源和坐标，报告几何误差。

**10．执行步骤与验收标准**

| 阶段 | 工作 | 通过标准 |
|---|---|---|
| A：几何基线 | 核对单位、六组装配、转向轴，生成坐标报告 | 零位与原整车网格对齐；关键尺寸与来源一致 |
| B：动态模型 | 建立四个 link、三个 joint、碰撞和惯性 | Sim 正常加载；两轮可滚动；前电机随转向架运动；无初始化爆炸 |
| C：限位 | 转向范围扫掠和双向受力限位测试 | 测试范围内每步实际角度均在 ±15° 内，关键部件无穿插；报告最小间隙及内部裕量 |
| D：钢桥物理 | 网格接触、孔洞、薄板两侧、接缝验证 | 物理碰撞与可见表面匹配，孔洞保持贯通，法向可解释 |
| E：磁吸基线 | 单轮与双轮、水平/竖直/倾斜/倒挂钢板 | 稳态施加合力每轮 200 N，建议数值容差 0.1 N；两轮同面 400 N；无重复累加 |
| F：负例 | 非钢面、孔洞、离面、越界、前轮连续自转 | 无错误吸附；离开范围释放；磁力方向不随轮子自转错误变化 |
| G：整车附着 | 各类平面连续至少 60 s 仿真时间 | 无非预期脱离、翻转、穿板和发散；静止测试明确记录是否使用轮轴锁定夹具 |
| H：滚动能力 | 用临时力矩沿代表性平面低速滚动 | 磁吸持续有效；轮子与车体运动一致；报告滑移及姿态变化，不作为控制器交付 |
| I：回归交付 | 重置、重复启动、实际桥梁场景、文档 | 能按 README 重现，插件加载失败可见，报告记录版本、步长和全部物理参数 |

先采用 1 ms 物理步长作为基线；若强磁力与小尺寸模型出现接触抖动，针对失败工况减小步长并比较结果，确定交付参数。施加磁力与碰撞求解采用物理步更新，避免受 GUI 帧率影响。

交付时区分“已核实输入”“临时物理参数”“已通过测试”和“后续控制待验证项”。

**11．实施结果与具体适配**

- 采用四个动态 link 和三个关节，整车质量精确合计 2.70 kg。
- 转向物理停止位置为 ±14.9°，保留 0.1° 裕量，外部边界仍为 ±15°；独立监测器发现越限时停止仿真。双向 5 N·m、20 rad/s 压力测试通过。
- Fortress DART 不支持 SDF `continuous` 关节；轮轴使用无有限角度限位的 `revolute`，已验证多圈滚动。
